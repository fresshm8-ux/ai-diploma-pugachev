# 🧠 ML Error Function Analyzer

## 📊 Описание проекта
Интерактивное приложение для анализа функции ошибки модели машинного обучения. Проект позволяет визуализировать функции ошибки, вычислять производные и демонстрировать работу алгоритмов оптимизации.

## 🚀 Возможности

- 📈 **Построение графиков** функции ошибки и её производной
- 🧮 **Анализ функции** (нахождение минимумов, поведение функции)
- 📐 **Вычисление производной** (аналитически и численно)
- ⚡ **Оптимизация** градиентным спуском и методом с моментом
- 💾 **Сохранение истории** в SQLite базу данных
- 📊 **Сравнение методов** оптимизации

## 🗄️ Структура базы данных

### Таблица `model_errors`
- Хранит историю каждой итерации оптимизации
- Параметр, ошибка, производная, скорость обучения

### Таблица `optimization_history`
- Результаты выполненных оптимизаций
- Тип оптимизатора, финальная ошибка, время выполнения
